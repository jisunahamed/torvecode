# TorveCode (টর্ভকোড)

**TorveCode** হলো Torve AI-এর অফিসিয়াল টার্মিনাল কোডিং এজেন্ট (CLI)। এটি ডেভেলপারদের টার্মিনাল থেকেই প্রজেক্ট পর্যবেক্ষণ, ফাইল এডিটিং, টার্মিনাল কমান্ড চালনা, গিট ডিভ পর্যালোচনা, সেশন ম্যানেজমেন্ট এবং এআই মডেল ব্যবহারের সুবিধা দেয়।

---

## ১. ইনস্টলেশন (Installation)

TorveCode একটি সাধারণ ও হালকা npm লঞ্চারের সাথে সব প্ল্যাটফর্মের প্রি-বিল্ট নেটিভ বাইনারি প্রদান করে। ব্যবহারকারীর কম্পিউটারে Go বা Bun ইনস্টল থাকার কোনো প্রয়োজন নেই।

```bash
# গ্লোবাল npm ইনস্টলেশন (সুপারিশকৃত)
npm install --global @torveai/cli@latest

# ইনস্টলেশন যাচাই
torve --version

# কোডিং শুরু করতে
torve
```

> [!TIP]
> উইন্ডোজে আপডেটের সময় যদি `EBUSY` এরর আসে, চলমান সকল TorveCode টার্মিনাল উইন্ডো বন্ধ করে কমান্ডটি আবার রান করুন।

### অন্যান্য ইনস্টলেশন মেথড:
- **Homebrew (macOS / Linux):** `brew install torveai/tap/torvecode`
- **Go ব্যবহার করে:** `go install github.com/jisunahamed/torvecode/cmd/torve@latest`

## ২. অথেন্টিকেশন ও কানেকশন (Authentication)

TorveCode আপনার Torve AI অ্যাকাউন্টের সাথে দুটি উপায়ে কানেক্ট হতে পারে:

### ক) ব্রাউজার দিয়ে ওয়েবসাইট কানেকশন
```bash
torve auth login
```
টার্মিনালে দেওয়া নির্দেশ অনুযায়ী ব্রাউজার খুলে আপনার Torve AI অ্যাকাউন্টে লগইন করে "Connect TorveCode" অ্যাপ্রুভ করলেই টার্মিনাল সেশন স্বয়ংক্রিয়ভাবে কানেক্ট হয়ে যাবে।

### খ) সরাসরি Torve API Key ব্যবহার
```bash
torve auth login --api-key
```
অথবা এনভায়রনমেন্ট ভেরিয়েবল সেট করে:
```bash
export TORVE_API_KEY="আপনার_টর্ভ_এপিআই_কি"
```

## ৩. দরকারি কমান্ডসমূহ (Commands)

```text
torve                         ইন্টারেক্টিভ কোডিং ইন্টারফেস শুরু করে
torve run "fix tests"         নন-ইন্টারেক্টিভ মোডে সরাসরি টাস্ক চালায়
torve models                  আপনার অ্যাকাউন্টে উপলব্ধ মডেল তালিকা দেখায়
torve auth login              Torve AI অ্যাকাউন্টে লগইন করে
torve auth status             বর্তমান অথেন্টিকেশন অবস্থা প্রদর্শন করে
torve auth logout             লোকাল লগইন ক্রেডেনশিয়াল মুছে ফেলে
torve update                  সর্বশেষ স্টেবল ভার্সনে আপডেট করে
torve doctor                  সিস্টেম ডায়াগনসিস চালায়
torve --help                  সকল কমান্ড ও অপশন দেখায়
```

ইন্টারফেসে কাজ করার সময় `/` টাইপ করে কমান্ড প্যালেট এবং `@` টাইপ করে ফাইল বা ডিরেক্টরি মেনশন করতে পারবেন। `Ctrl + C` দিয়ে কোড জেনারেশন বন্ধ করা যায় এবং `Esc` দিয়ে যেকোনো মেনু ক্লোজ করা যায়।
